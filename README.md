# Menu-Website-Project

I built this project to solve a problem I always face going back home to my dad for the summer, which is deciding what to cook. I wanted something simple that could help me decide based on what I'm craving or what I have in mind, and this menu/recipe generator does just what I need.

I'd love to prefect this project more and work on it when I have more freetime.
My plan is to expand the menu and perhaps find another API that gives more options overall, especially in the Afrian Cuisine section.

# Usage

- Search for recipes by flavor or ingredient (e.g. "chicken", "pasta", "beef")
- Filter results by cuisine (African, European, Asian, American, etc)
- View full recipes via external links
- Refresh for new suggestions if you don’t like the current ones
- Responsive and clean UI
- Built with HTML, CSS, and JavaScript

# How to

1. Open "index.html" in your browser
2. Type in a flavor or ingredient
3. Press enter or click the search glass icon
5. On the results page, filter by cuisine if desired or click "Show Me More" to refresh
6. Click "View Recipe" to see full instructions on Spoonacular

# API

This project uses the [Spoonacular API](https://spoonacular.com/food-api).
